# issue FFTの倍音のx1～x12の仕様を改善する #178
[issues #178](https://github.com/cat2151/web-ym2151/issues/178)

- これまでの課題。MUL 0 つまり1/2 freq があるときは、FFT左端にx1～x12が集中し、本当に見たい「高MULがあった場合にそこが示すpeak」が可視化されていなかった
- 対策。4つのMULそれぞれが示す周波数倍率の場所に、x1/2 x1 x2 などを表示する。色をオペレータごとに4つのmonokai色にすることで、重ねて表示しても区別しやすくする。これは重なって表示してよい、4つ表示することを優先する
- 例、KC KF から算出した周波数が440Hzで、かつMUL が4つのオペレータすべてで 1 だった場合は、倍率1なので、440Hzの場所に、x1 を4つ重ねて表示する。
