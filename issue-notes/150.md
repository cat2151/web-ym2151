# issue ランダム音色は、検証用に、ALG0～7それぞれについて、キャリアとFBが多重にかかるものは、TLを0固定でなくランダムにする #150
[issues #150](https://github.com/cat2151/web-ym2151/issues/150)

- これまでの課題。ALG0などモジュレータが多重にかかるものは、noiseになりやすかった
- 対策。ALGごとに、キャリアごとのモジュレータとの接続段数listを、PRコメントに書く
- 例、ALG0のキャリアは1つで、モジュレータが3つにFBが1つかかっている、ので変調段数を仮の基準で、4、とする
- 例、ALG7は、キャリアが4つあり、OP0はFBが1つで変調段数は1、あとはFBが0で変調段数が0、である
- キャリアTLは引き続き0固定。
- 変調段数 0 のキャリアにつながるモジュレータは、モジュレータTLは0x00固定とする。
- 変調段数 1 のキャリアにつながるモジュレータは、モジュレータTLは0x08固定とする。
- 変調段数 2 のキャリアにつながるモジュレータは、モジュレータTLは0x10固定とする。
- 変調段数 3 のキャリアにつながるモジュレータは、モジュレータTLは0x18固定とする。
- 変調段数 4 のキャリアにつながるモジュレータは、モジュレータTLは0x20固定とする。
- これらは検証用。折りたたみでランダム設定欄をつけて、この法則をJSON textareaで調整可能にするつもり。
