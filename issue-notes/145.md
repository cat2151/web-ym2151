# issue Simple Tone Editor 欄の下に、registers音色フォーマット欄を用意する #145
[issues #145](https://github.com/cat2151/web-ym2151/issues/145)

- 参考URL : https://github.com/cat2151/ym2151-tone-editor/blob/main/tones/general_midi/000_AcousticGrand.json

- 仮フォーマット例：

```
{"type":"YM2151 tone","note_number":60,"registers":"40016014801FA00AC005E0574801681E8819A808C804E866500270009014B006D003F075580178009816B807D804F86620C4283E30000878"}
```

- 自己記述的なデータとする。よって、YM2151 tone という文字列を入れる。
- これ自体はProgramChange番号を持たず、「ProgramChange定義が、このデータをメンバとして保持することを想定」とする
  
- registers の文字列フォーマット :
  - 2bytes : 対象レジスタのアドレスを16進数で記載
  - 2bytes : 対象データ値を16進数で記載
  - 以降、繰り返し

- 他の欄で音色を編集やランダム音色を決定した場合などには、その音色を、registers音色フォーマット欄に反映する

- registers音色フォーマット欄を編集した場合には、その音色で演奏する（ほかの欄にも反映する）
