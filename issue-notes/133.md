# issue demoにおいて、折りたたみで「直近で無らしたパラメタとwavを、20個の履歴」「最大20個のお気に入りlist」として用意する #133
[issues #133](https://github.com/cat2151/web-ym2151/issues/133)

- より具体的なGUIについては、voicevox-playground の、履歴20件と、お気に入り20件、のGUIを参考にすること

- メリットとして、voicevox-playground で検証済みの有用なUXを提供できること、がある

- さらに、それら40件は、裏でidle中に1つずつレンダリングしてcacheとして保持しておく

- さらに、cacheシステムを導入する。keyがレンダリング処理に与えるパラメタ全て、valueがwav波形となる。直近の100件をcacheで保持する
- メリットは、履歴とお気に入りでの再生とチェックがスムーズになり、UXが改善されること、である
